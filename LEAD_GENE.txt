## 2. Project Overview

Project name: LeadFlow CRM

Build a web-based lead generation and management application for a company that imports leads from Excel or CSV files, assigns leads to employees, tracks customer interactions, schedules follow-ups, manages reminders, and monitors sales performance.

The application must contain two panels in the SAME project:

1. Admin Panel

## 7. Excel/CSV Import — Most Important Feature

The application must support importing leads from `.xlsx` and `.csv` files using one fixed, downloadable template.

Only administrators can upload or import lead files.

### Template columns

Use these exact column headers:

1. Lead Name
2. Company Name
3. Phone Number
4. Email
5. City
6. Lead Source
7. Interested Product/Service
8. Estimated Deal Value
9. Priority
10. Remarks

Generate the template through a backend endpoint or a frontend utility and make it downloadable.

Provide:
- Excel template
- CSV template
- Example row
- Clear instructions for filling the template

Do not require the user to manually enter lead IDs, status, creation timestamps, or assigned user IDs in the uploaded file.

### Import workflow

Step 1: Download the template.

Step 2: Complete the template in Excel or another spreadsheet application.

Step 3: Upload the file.

Step 4: Validate the file on the server.

Step 5: Preview the results before importing.

Step 6: Show a clear summary:
- Total rows
- Valid rows
- Invalid rows
- Potential duplicates

Step 7: Display a preview table with row number, lead name, phone, email, validation status, and error reason.

Step 8: Allow the admin to download a detailed error report.

Step 9: Allow the admin to confirm importing valid rows.

Step 10: Save the imported leads and import batch history.

Step 11: Display the final import result.

### Validation rules
- Required columns must exist.
- Missing required values must be flagged.
- Validate phone and email formats reasonably.
- Validate estimated deal values as non-negative numbers.
- Normalize priority values.
- Trim unnecessary spaces.
- Handle empty optional fields.
- Handle malformed CSV files.
- Handle missing or renamed column headers.
- Prevent spreadsheet formulas from being treated as trusted values.
- Enforce a configurable upload size and row limit.
- Never execute uploaded spreadsheet formulas.

### Duplicate detection
Detect likely duplicates using normalized phone number and email where available.

Do not automatically overwrite an existing lead.

Show potential duplicates and allow the administrator to skip them or explicitly confirm importing when appropriate.

Avoid duplicate creation within the same upload batch.

### Import reliability
- Do not write records to the live leads table before validation and confirmation.
- Save import results and error information.
- Avoid partial or inconsistent imports.
- Use safe batching or database transactions.
- Keep a clear import status.
- Prevent double-submission from creating duplicate records.
- Handle large files within configured limits.

The import page should look polished and easy to use.
